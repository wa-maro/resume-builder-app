## Overview

ResumeX is a web application for building and managing professional resumes.

It provides a structured and intuitive workflow for creating resumes, organizing career information, and maintaining multiple resume versions in one place.

With ResumeX, you can create and manage:

- ✅ Personal & Contact Information
- ✅ Education Background
- ✅ Work Experience
- ✅ Skills & Certifications
- ✅ Projects & Achievements
- ✅ Referees

## Features

- 📝 Build professional resumes with structured sections
- 💾 Save and manage multiple resumes
- 🔄 Update resume information without starting over
- 🎨 Choose and customize resume templates
- 📄 Generate print-ready resumes (PDF)
